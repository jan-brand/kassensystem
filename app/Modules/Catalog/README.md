# Catalog

Verwaltet Kategorien und Produkte für die Kassenoberfläche.

## V1-Regeln

- Geldbeträge werden als Integer in Cent gespeichert.
- Preise dürfen `0` sein, aber niemals negativ.
- Produkte und Kategorien werden deaktiviert statt gelöscht.
- Die Reihenfolge der Kategorien und Produkte ist frei konfigurierbar.
