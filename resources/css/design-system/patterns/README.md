# Patterns

Patterns kombinieren Components zu wiederkehrenden Gastro-Abläufen.

Sinnvolle spätere Patterns:

- ProductGrid
- CategoryRail
- CartPanel
- PaymentPanel
- TableOverview
- POSHeader
- FormActions
- ConfirmationSheet

Patterns definieren Struktur und Verhalten, aber keine neuen Farbwerte.
